# Compass Launcher 多语言架构设计

## 概述

Compass Launcher 采用**多语言混合架构**，充分利用各语言生态优势：

- **.NET (C#)**：Minecraft 核心功能（基于 [CmlLib.Core](https://github.com/CmlLib/CmlLib.Core)）
- **Rust**：Tauri UI 外壳、系统调用、业务逻辑
- **Python**：AI 服务、模型推理
- **TypeScript/React**：前端用户界面

使用 **Nx Monorepo** 工具统一管理多语言项目，通过 **gRPC** 实现跨语言通信。

```protobuf
  rpc RefreshToken(RefreshRequest) returns (Account);
}

  bool include_snapshots = 1;
}

  repeated Version versions = 1;
}

  string id = 1;
  string type = 2;  // release, snapshot, old_beta, old_alpha
  string release_time = 3;
  string url = 4;
}

message InstallVersionRequest {
  string version_id = 1;
  string game_directory = 2;
}

message LaunchGameRequest {
  string version_id = 1;
  string instance_id = 2;
  string java_path = 3;
  int32 max_memory = 4;
  string game_directory = 5;

}

  string process_id = 1;
  int32 pid = 2;
}

  string uuid = 1;
  string username = 2;
  string access_token = 3;
  string account_type = 4;  // microsoft, offline (避免使用保留关键字 'type')
```

**gRPC 服务实现**：

```csharp
// Services/MinecraftServiceImpl.cs
using CmlLib.Core;
using CmlLib.Core.Auth;
using CmlLib.Core.Installer;
using Grpc.Core;

public class MinecraftServiceImpl : MinecraftService.MinecraftServiceBase
{
    private readonly MinecraftPath _minecraftPath;
    private readonly CMLauncher _launcher;
    private readonly Dictionary<string, Process> _runningGames = new();

    public MinecraftServiceImpl()
    {
        _minecraftPath = new MinecraftPath();
        _launcher = new CMLauncher(_minecraftPath);
    }

    public override async Task<GetVersionsResponse> GetVersions(
        GetVersionsRequest request,
        ServerCallContext context)
    {
        var versions = await _launcher.GetAllVersionsAsync();

        var response = new GetVersionsResponse();
        foreach (var v in versions)
        {
            if (!request.IncludeSnapshots && v.Type != "release")
                continue;

            response.Versions.Add(new Version
            {
                Id = v.Id,
                Type = v.Type,
                ReleaseTime = v.ReleaseTime.ToString(),
                Url = v.Url
            });
        }

        return response;
    }

    public override async Task LaunchGame(
        LaunchGameRequest request,
        IServerStreamWriter<Progress> responseStream,
        ServerCallContext context)
    {
        var launchOption = new MLaunchOption
        {
            MaximumRamMb = request.MaxMemory,
            Session = new MSession
            {
                Username = request.Account.Username,
                AccessToken = request.Account.AccessToken,
                UUID = request.Account.Uuid
            }
        };

        var process = await _launcher.CreateProcessAsync(
            request.VersionId,
            launchOption);

        _runningGames[request.InstanceId] = process;
        process.Start();

        // 发送进度更新
        await responseStream.WriteAsync(new Progress
        {
            Stage = "launched",
            Message = $"Game started with PID {process.Id}"
        });
    }
}
```

```python
# src/compass_ai/server.py
import grpc
from concurrent import futures

from generated import ai_pb2, ai_pb2_grpc
from services.crash_analyzer import CrashAnalyzer
from services.config_optimizer import ConfigOptimizer
from services.chat_service import ChatService


class AiServiceImpl(ai_pb2_grpc.AiServiceServicer):
    def __init__(self):
        self.crash_analyzer = CrashAnalyzer()
        self.config_optimizer = ConfigOptimizer()
        self.chat_service = ChatService()

    def AnalyzeCrash(self, request, context):
        """分析崩溃日志"""
        analysis = self.crash_analyzer.analyze(
            log_content=request.log_content,
            mod_list=list(request.mod_list)
        )

        return ai_pb2.CrashAnalysis(
            crash_type=analysis.crash_type,
            severity=analysis.severity,
            analysis=analysis.analysis,
            involved_mods=analysis.involved_mods,
            suggestions=[
                ai_pb2.Suggestion(
                    action=s.action,
                    target=s.target,
                    reason=s.reason
                )
                for s in analysis.suggestions
            ],
            auto_fixable=analysis.auto_fixable
        )

    def OptimizeConfig(self, request, context):
        """优化配置建议"""
        suggestion = self.config_optimizer.optimize(
            specs=request.specs,
            profile=request.profile
        )

        return ai_pb2.ConfigSuggestion(
            hardware_tier=suggestion.hardware_tier,
            jvm_args=suggestion.jvm_args,
            game_settings=ai_pb2.GameSettings(
                render_distance=suggestion.render_distance,
                simulation_distance=suggestion.simulation_distance,
            ),
            mod_suggestions=[
                ai_pb2.ModSuggestion(name=m.name, reason=m.reason)
                for m in suggestion.mod_suggestions
            ]
        )

    def Chat(self, request, context):
        """游戏向导聊天"""
        reply = self.chat_service.chat(
            message=request.message,
            history=[
                {"role": m.role, "content": m.content}
                for m in request.history
            ],
            context=request.context
        )

        return ai_pb2.ChatResponse(reply=reply)

    def ChatStream(self, request, context):
        """流式聊天响应"""
        for chunk in self.chat_service.chat_stream(
            message=request.message,
            history=request.history
        ):
            yield ai_pb2.ChatStreamResponse(chunk=chunk)


def serve():
    server = grpc.server(futures.ThreadPoolExecutor(max_workers=10))
    ai_pb2_grpc.add_AiServiceServicer_to_server(AiServiceImpl(), server)
    # 仅绑定本地地址，避免暴露到外网
    server.add_insecure_port("127.0.0.1:50052")
    server.start()
    print("AI Service started on 127.0.0.1:50052")
    server.wait_for_termination()


if __name__ == "__main__":
    serve()
```

**崩溃分析服务**：

```python
# src/compass_ai/services/crash_analyzer.py
import re
from dataclasses import dataclass
from typing import List


@dataclass
class Suggestion:
    action: str
    target: str
    reason: str


@dataclass
class CrashAnalysisResult:
    crash_type: str
    severity: str
    analysis: str
    involved_mods: List[str]
    suggestions: List[Suggestion]
    auto_fixable: bool


class CrashAnalyzer:
    """崩溃日志分析器"""

    # 常见崩溃模式
    PATTERNS = {
        "out_of_memory": {
            "patterns": ["OutOfMemoryError", "java.lang.OutOfMemoryError"],
            "type": "内存溢出",
            "severity": "high",
        },
        "mod_conflict": {
            "patterns": ["DuplicateModsFoundException", "ModResolutionException"],
            "type": "Mod 冲突",
            "severity": "high",
        },
        "graphics_driver": {
            "patterns": ["GLFW error", "OpenGL error", "Pixel format not accelerated"],
            "type": "显卡驱动问题",
            "severity": "medium",
        },
        "java_version": {
            "patterns": ["UnsupportedClassVersionError", "java.lang.UnsupportedClassVersionError"],
            "type": "Java 版本不兼容",
            "severity": "medium",
        },
    }

    def analyze(self, log_content: str, mod_list: List[str]) -> CrashAnalysisResult:
        """分析崩溃日志"""

        # 检测崩溃类型
        crash_type = None
        for key, info in self.PATTERNS.items():
            for pattern in info["patterns"]:
                if pattern in log_content:
                    crash_type = key
                    break
            if crash_type:
                break

        if not crash_type:
            return CrashAnalysisResult(
                crash_type="未知",
                severity="low",
                analysis="无法识别的崩溃类型",
                involved_mods=[],
                suggestions=[],
                auto_fixable=False
            )

        pattern_info = self.PATTERNS[crash_type]

        # 提取涉及的 Mod
        involved_mods = self._extract_mods(log_content, mod_list)

        # 生成建议
        suggestions = self._generate_suggestions(crash_type, involved_mods)

        return CrashAnalysisResult(
            crash_type=pattern_info["type"],
            severity=pattern_info["severity"],
            analysis=self._generate_analysis(crash_type, involved_mods),
            involved_mods=involved_mods,
            suggestions=suggestions,
            auto_fixable=len(suggestions) > 0 and suggestions[0].action in ["remove", "update"]
        )

    def _extract_mods(self, log_content: str, mod_list: List[str]) -> List[str]:
        """从日志中提取涉及的 Mod"""
        involved = []
        for mod in mod_list:
            if mod.lower() in log_content.lower():
                involved.append(mod)
        return involved

    def _generate_suggestions(self, crash_type: str, involved_mods: List[str]) -> List[Suggestion]:
        """生成修复建议"""
        suggestions = []

        if crash_type == "out_of_memory":
            suggestions.append(Suggestion(
                action="config",
                target="jvm_args",
                reason="建议增加 -Xmx 参数分配更多内存"
            ))
        elif crash_type == "mod_conflict" and involved_mods:
            suggestions.append(Suggestion(
                action="remove",
                target=involved_mods[0],
                reason=f"{involved_mods[0]} 可能与其他 Mod 冲突"
            ))

        return suggestions
```

```rust
    grpc_clients: State<'_, GrpcClients>,
) -> Result<String, String> {
    let mut client = grpc_clients.minecraft.clone();

    let request = tonic::Request::new(minecraft::LaunchGameRequest {
        version_id: "1.20.1".to_string(),
        instance_id: instance_id.clone(),
        java_path: "/path/to/java".to_string(),
        max_memory: 4096,
        game_directory: "/path/to/.minecraft".to_string(),
        jvm_args: vec!["-XX:+UseG1GC".to_string()],
        account: Some(minecraft::Account {
            uuid: "...".to_string(),
            username: "Player".to_string(),
            access_token: "...".to_string(),
            account_type: "microsoft".to_string(),
        }),
    });

    let response = client.launch_game(request).await
        .map_err(|e| e.to_string())?;

    Ok(response.into_inner().process_id)
}

#[tauri::command]
pub async fn analyze_crash(
    instance_id: String,
    grpc_clients: State<'_, GrpcClients>,
) -> Result<String, String> {
    // 1. 读取崩溃日志
    let log_content = std::fs::read_to_string(
        format!("/path/to/instances/{}/crash-reports/latest.log", instance_id)
    ).map_err(|e| e.to_string())?;

    // 2. 调用 AI 服务分析
    let mut client = grpc_clients.ai.clone();

    let request = tonic::Request::new(ai::AnalyzeCrashRequest {
        log_content,
        instance_id,
        mod_list: vec![],  // 从实例配置获取
    });

    let response = client.analyze_crash(request).await
        .map_err(|e| e.to_string())?;

    let analysis = response.into_inner();

    // 3. 返回分析结果
    Ok(format!(
        "崩溃类型: {}\n严重程度: {}\n分析: {}\n建议: {}",
        analysis.crash_type,
        analysis.severity,
        analysis.analysis,
        analysis.suggestions.iter()
            .map(|s| format!("- {}: {} ({})", s.action, s.target, s.reason))
            .collect::<Vec<_>>()
            .join("\n")
    ))
}
```

## 最佳实践

### 1. 接口稳定性

- gRPC 协议变更需保持向后兼容
- 使用 `optional` 字段和默认值
- 版本号管理：`v1`、`v2` 等

### 2. 错误处理

```protobuf
message ErrorDetails {
  string code = 1;
  string message = 2;
  map<string, string> metadata = 3;
}
```

### 3. 性能优化

- 使用 gRPC 流式传输大文件
- 本地服务使用 Unix Domain Socket（比 TCP 快）
- 连接池复用 gRPC 连接

### 4. 安全考虑

- 本地服务绑定 `127.0.0.1`，不暴露外网
- 敏感数据（Token）只存储在 Rust 层
- 服务间通信可添加简单认证
