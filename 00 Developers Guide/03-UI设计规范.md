# Compass Launcher UI 设计规范

## 设计理念

### 游戏风格主题

Compass Launcher 采用 **Minecraft 游戏风格** 设计，融入像素元素和游戏氛围，同时保持现代 UI 的易用性。

### 设计原则

1. **沉浸式体验** - 让玩家感受到 Minecraft 的世界观
2. **清晰易用** - 功能一目了然，操作直观
3. **性能优先** - 流畅的动画，快速响应
4. **可定制性** - 支持主题和个性化设置

## 动画规范

### 过渡时间

| 类型 | 时长  | 缓动函数                     |
| ---- | ----- | ---------------------------- |
| 快速 | 150ms | ease-out                     |
| 正常 | 200ms | ease-in-out                  |
| 缓慢 | 300ms | ease-in-out                  |
| 复杂 | 400ms | cubic-bezier(0.4, 0, 0.2, 1) |

### 常用动画

#### 悬停上浮

```css
transition:
    transform 200ms ease-out,
    box-shadow 200ms ease-out;
:hover {
    transform: translateY(-2px);
    box-shadow: 0 8px 16px rgba(0, 0, 0, 0.3);
}
```

#### 按钮点击

```css
transition: transform 100ms ease-out;
:active {
    transform: scale(0.98);
}
```

#### 页面切换

```css
transition:
    opacity 300ms ease-in-out,
    transform 300ms ease-in-out;
.enter {
    opacity: 0;
    transform: translateX(20px);
}
.enter-active {
    opacity: 1;
    transform: translateX(0);
}
```

#### 加载动画

```css
@keyframes pulse {
    0%,
    100% {
        opacity: 1;
    }
    50% {
        opacity: 0.5;
    }
}
animation: pulse 1.5s ease-in-out infinite;
```

| ----- | ------ | -------- |

| `md`  | 768px  | 平板     |
| `lg`  | 1024px | 小桌面   |
| `xl`  | 1280px | 标准桌面 |
| `2xl` | 1536px | 大桌面   |

### 布局适配

- **侧边栏**: 固定 64px，始终显示
- **内容区**: 自适应宽度
- **卡片网格**:
    - xl: 4列
    - lg: 3列
    - md: 2列
    - sm: 1列

## 主题变量 (Tailwind)

```css
/* CSS 变量方式 (TailwindCSS v4) */
/* 在 src/index.css 或全局 CSS 文件中定义 */

@import "tailwindcss";

@theme {
    /* 主色调 */
    --color-primary: #5D8C3A;
    --color-primary-dark: #4A7030;
    --color-primary-light: #7FB347;
    --color-secondary: #8B6914;
    
    /* 背景色 */
    --color-bg-default: #1A1A1A;
    --color-bg-card: #2D2D2D;
    --color-bg-input: #3D3D3D;
    
    /* Minecraft 主题色 */
    --color-mc-diamond: #00FFFF;
    --color-mc-gold: #FFD700;
    --color-mc-redstone: #B02E26;
    --color-mc-lapis: #2C2E8F;
    
    /* 字体 */
    --font-sans: "Inter", system-ui, sans-serif;
    --font-pixel: "VT323", monospace;
    --font-mono: "JetBrains Mono", monospace;
    
    /* 动画 */
    --animate-pulse-glow: pulse-glow 2s ease-in-out infinite;
}

@keyframes pulse-glow {
    0%, 100% { box-shadow: 0 0 20px rgba(93,140,58,0.3); }
    50% { box-shadow: 0 0 30px rgba(93,140,58,0.5); }
}
```

```javascript
// Vite 配置 (vite.config.ts)
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
    plugins: [
        react(),
        tailwindcss(), // TailwindCSS v4 Vite 插件
    ],
});
```

> **TailwindCSS v4 变化**:
> - 不再使用 `tailwind.config.js`，改用 CSS 变量
> - 使用 `@import "tailwindcss"` 替代 `@tailwind` 指令
> - 使用 `@theme` 块定义自定义变量
> - 需要 `@tailwindcss/vite` 插件
