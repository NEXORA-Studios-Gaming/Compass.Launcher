# Compass Launcher 包结构与组件复用设计

## 概述

Compass Launcher 采用 **混合包结构**：
- **前端**：React + TypeScript + Tauri
- **后端 Core**：.NET 类库（复用现有生态）
- **互操作层**：gRPC 实现 Rust 与 .NET 通信

这种设计既利用了 Tauri 的跨平台桌面能力，又通过 .NET 复用了成熟的 Minecraft 生态库，加快开发速度。

**gRPC 服务示例**：

```csharp
// Services/MinecraftService.cs
public class MinecraftService : Minecraft.MinecraftBase
{
    private readonly VersionManager _versionManager;
    private readonly Launcher _launcher;

    public override async Task<GetVersionsResponse> GetVersions(
        GetVersionsRequest request, ServerCallContext context)
    {
        var versions = await _versionManager.FetchVersionsAsync();
        return new GetVersionsResponse {
            Versions = { versions.Select(v => v.ToGrpc()) }
        };
    }

    public override async Task<LaunchResponse> Launch(
        LaunchRequest request, IServerStreamWriter<LogMessage> responseStream, ServerCallContext context)
    {
        var options = request.ToLaunchOptions();
        await foreach (var log in _launcher.LaunchAsync(options))
        {
            await responseStream.WriteAsync(new LogMessage { Content = log });
        }
        return new LaunchResponse { Success = true };
    }
}
```

**minecraft.proto 示例**：

```protobuf
syntax = "proto3";
package compass.minecraft;

service Minecraft {
  rpc GetVersions(GetVersionsRequest) returns (GetVersionsResponse);
  rpc GetVersionDetail(GetVersionDetailRequest) returns (VersionDetail);
  rpc InstallVersion(InstallVersionRequest) returns (stream ProgressMessage);
  rpc Launch(LaunchRequest) returns (stream LogMessage);
}

message GetVersionsRequest {
  bool include_snapshots = 1;
}

message GetVersionsResponse {
  repeated VersionInfo versions = 1;
}

message VersionInfo {
  string id = 1;
  string type = 2;  // release, snapshot, old_alpha, old_beta
  string release_time = 3;
  string url = 4;
}

message LaunchRequest {
  string instance_id = 1;
  string version_id = 2;
  string java_path = 3;
  int32 max_memory = 4;
  string game_directory = 5;
  repeated string jvm_args = 6;
  repeated string game_args = 7;
}

message LogMessage {
  string level = 1;  // INFO, WARN, ERROR
  string content = 2;
  int64 timestamp = 3;
}

message ProgressMessage {
  string stage = 1;
  float progress = 2;  // 0.0 - 1.0
  string detail = 3;
}

```rust
// src/core_client/mod.rs
use std::process::Command;
use tonic::transport::Channel;

pub struct CoreServiceManager {
    process: Option<std::process::Child>,
    client: Option<MinecraftClient<Channel>>,
}

impl CoreServiceManager {
    pub async fn start() -> Result<Self> {
        // 启动 .NET Core 服务进程
        let process = Command::new("dotnet")
            .arg("Compass.Core.dll")
            .arg("--urls")
            .arg("http://localhost:50051")
            .spawn()?;

        // 等待服务就绪
        tokio::time::sleep(Duration::from_millis(500)).await;

        // 连接 gRPC
        let channel = Channel::from_static("http://localhost:50051")
            .connect()
            .await?;
        let client = MinecraftClient::new(channel);

        Ok(Self {
            process: Some(process),
            client: Some(client),
        })
    }

    pub fn client(&self) -> Option<&MinecraftClient<Channel>> {
        self.client.as_ref()
    }

    pub async fn stop(&mut self) -> Result<()> {
        if let Some(mut process) = self.process.take() {
            process.kill()?;
        }
        Ok(())
    }
}
```

**IPC 命令示例**：

```rust
// src/commands/minecraft.rs
#[tauri::command]
pub async fn get_versions(
    state: State<'_, CoreServiceManager>,
    include_snapshots: bool,
) -> Result<Vec<VersionInfo>, String> {
    let client = state.client().ok_or("Core service not ready")?;

    let request = GetVersionsRequest {
        include_snapshots,
    };

    let response = client
        .get_versions(request)
        .await
        .map_err(|e| e.to_string())?;

    Ok(response.into_inner().versions)
}

#[tauri::command]
pub async fn launch_instance(
    state: State<'_, CoreServiceManager>,
    instance_id: String,
) -> Result<Stream<LogMessage>, String> {
    let client = state.client().ok_or("Core service not ready")?;

    let request = LaunchRequest {
        instance_id,
        ..Default::default()
    };

    let stream = client
        .launch(request)
        .await
        .map_err(|e| e.to_string())?
        .into_inner();

    Ok(Stream::new(stream))
}

1. **构建 .NET Core 服务**
   ```bash

## 最佳实践

### 架构设计原则

1. **Core 服务无状态**: 便于重启和扩展
2. **gRPC 流式响应**: 用于日志、下载进度等实时数据
3. **错误处理**: .NET 端使用 `RpcException`，Rust 端转换为 Tauri 错误
4. **配置共享**: 通过文件系统共享配置，避免双写

### 性能考虑

1. **gRPC 本地通信**: 使用 Unix Domain Socket (Linux/macOS) 或 Named Pipe (Windows)
2. **Core 服务生命周期**: Tauri 启动时启动，关闭时优雅退出
3. **内存管理**: .NET GC + Rust 所有权，各自管理自己的内存

## 最佳实践

### 包设计原则

1. **单一职责**：每个包只负责一个领域
2. **最小依赖**：减少外部依赖，优先使用标准库
3. **向后兼容**：公共 API 变更遵循 SemVer
4. **文档优先**：公共 API 必须有文档和示例

### 依赖管理

1. **Workspace 统一版本**：公共依赖在 Workspace 定义
2. **特性标志**：使用 features 控制可选功能
3. **避免循环依赖**：包之间不能循环依赖

### 代码复用

1. **优先使用 compass-core**：通用工具放在 core
2. **不要重复实现**：已有功能直接依赖对应包
3. **保持接口稳定**：公共 API 变更需要谨慎
