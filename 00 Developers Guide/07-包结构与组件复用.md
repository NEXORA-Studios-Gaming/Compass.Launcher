# Compass Launcher 包结构与组件复用设计

## 概述

Compass Launcher 采用 **混合包结构**：核心启动器作为独立应用，通用组件拆分为可复用的独立包。这种设计既保证了启动器的完整性，又便于组件在其他项目中复用。

## 包结构总览


### 2. compass-config - 配置管理库

**定位**：分层配置管理，支持多格式、热重载

**功能**：

- JSON/YAML/TOML 多格式支持
- 四层配置优先级（静态/文件/环境/运行时）
- Schema 验证和类型检查
- 配置热重载监听
- 变更通知机制

**Cargo.toml**：

```toml
[package]
name = "compass-config"
version.workspace = true

[dependencies]
compass-core = { workspace = true }

serde = { workspace = true }
serde_json = "1.0"
serde_yaml = "0.9"
toml = "0.8"

notify = "6.0"          # 文件变更监听
schemars = "0.8"        # JSON Schema
validator = "0.16"      # 验证

[features]
default = ["json", "yaml", "toml"]
json = []
yaml = []
toml = []
hot-reload = ["notify"]
```

**使用示例**：

```rust
use compass_config::{ConfigManager, ConfigSource};

// 创建配置管理器
let config = ConfigManager::builder()
    .with_static(include_str!("../config/default.json"))
    .with_file("config.json")
    .with_env_prefix("COMPASS")
    .build()
    .await?;

// 获取配置值
let max_memory: i32 = config.get("game.max_memory")?.unwrap_or(4096);

// 监听配置变更
config.on_change(|key, old, new| {
    println!("Config changed: {} = {:?}", key, new);
});
```

### 3. compass-download - 下载管理器

**定位**：高性能异步下载库，支持多线程、断点续传、镜像源

**功能**：

- 多线程并发下载
- 断点续传支持
- 多镜像源自动切换
- 下载队列管理
- SHA1/MD5 校验验证
- 下载进度回调

**Cargo.toml**：

```toml
[package]
name = "compass-download"
version.workspace = true

[dependencies]
compass-core = { workspace = true }

reqwest = { workspace = true }
tokio = { workspace = true }

futures = "0.3"
bytes = "1.5"
pin-project = "1.1"

# 并发控制
tokio-util = { version = "0.7", features = ["codec"] }

[dev-dependencies]
wiremock = "0.6"
tempfile = "3.8"
```

**使用示例**：

```rust
use compass_download::{DownloadManager, DownloadOptions, MirrorConfig};

// 创建下载管理器
let manager = DownloadManager::builder()
    .max_concurrent(8)
    .with_mirror(MirrorConfig {
        name: "bmclapi".to_string(),
        base_url: "https://bmclapi2.bangbang93.com".to_string(),
        priority: 1,
    })
    .build();

// 下载文件
let task = manager.download(
    "https://example.com/file.zip",
    "/path/to/save.zip",
    DownloadOptions::default()
        .with_checksum(Checksum::Sha1("abc123...".to_string()))
        .on_progress(|downloaded, total, speed| {
            println!("Progress: {}/{} ({}/s)", downloaded, total, speed);
        }),
).await?;

// 断点续传
let task = manager.resume_download(
    "https://example.com/large-file.zip",
    "/path/to/save.zip",
).await?;
```

### 4. compass-auth - 认证模块

**定位**：Minecraft 账号认证，支持 Microsoft/离线模式

**功能**：

- Microsoft OAuth 2.0 流程
- Xbox Live 身份验证
- Minecraft 服务验证
- 离线模式支持
- Token 刷新和缓存

> **注意**: Mojang 账号系统已于 2023 年 3 月完全迁移至 Microsoft 账号，不再支持独立的 Mojang 认证

**Cargo.toml**：

```toml
[package]
name = "compass-auth"
version.workspace = true

[dependencies]
compass-core = { workspace = true }

reqwest = { workspace = true }
serde = { workspace = true }
tokio = { workspace = true }

oauth2 = "4.4"
jsonwebtoken = "9.2"
keyring = "2.0"          # 系统密钥链
uuid = { version = "1.6", features = ["v4", "serde"] }

[features]
default = ["microsoft", "offline"]
microsoft = ["oauth2"]
offline = []
```

**使用示例**：

```rust
use compass_auth::{AuthProvider, MicrosoftAuth, Account};

// Microsoft 认证
let provider = MicrosoftAuth::new(
    "client_id",
    "redirect_uri",
);

// 获取授权 URL
let auth_url = provider.get_auth_url();

// 使用授权码完成认证
let account: Account = provider.authenticate("auth_code").await?;

// 刷新 Token
let refreshed = provider.refresh(&account.refresh_token).await?;

// 保存到系统密钥链
account.save_to_keyring()?;
```

### 5. compass-minecraft - Minecraft 核心库

**定位**：完整的 Minecraft 启动和管理库

**功能**：

- 版本清单获取和解析
- 版本 JSON 处理
- Libraries 和 Assets 下载
- 游戏启动参数构建
- Mod 加载器安装（Forge/Fabric/Quilt）
- 进程管理和监控

**Cargo.toml**：

```toml
[package]
name = "compass-minecraft"
version.workspace = true

[dependencies]
compass-core = { workspace = true }
compass-config = { workspace = true }
compass-download = { workspace = true }
compass-auth = { workspace = true }

serde = { workspace = true }
serde_json = { workspace = true }
tokio = { workspace = true }
tracing = { workspace = true }

# 版本解析
semver = "1.0"

# 进程管理
sysinfo = "0.30"

# ZIP 处理（整合包安装）
zip = "0.6"

[features]
default = ["forge", "fabric", "quilt"]
forge = []
fabric = []
quilt = []
```

**使用示例**：

```rust
use compass_minecraft::{
    VersionManager, LaunchOptions,
    ModLoader, ForgeInstaller
};

// 版本管理
let version_mgr = VersionManager::new().await?;

// 获取版本列表
let versions = version_mgr.fetch_versions().await?;

// 安装版本
version_mgr.install_version("1.20.1").await?;

// 安装 Forge
let forge = ForgeInstaller::new("1.20.1", "47.2.0");
forge.install().await?;

// 启动游戏
let options = LaunchOptions {
    version_id: "1.20.1-forge-47.2.0".to_string(),
    java_path: "/path/to/java".into(),
    max_memory: 4096,
    game_dir: "/path/to/.minecraft".into(),
    ..Default::default()
};

let process = version_mgr.launch(options).await?;
```

## 发布策略

### 阶段一：内部开发（当前）

- 所有包使用 `path` 依赖
- 版本号统一管理在 Workspace
- 不发布到 crates.io

### 阶段二：稳定后发布

| 包                | 发布策略  | 说明                   |
| ----------------- | --------- | ---------------------- |
| compass-core      | crates.io | 通用工具，完全开源     |
| compass-config    | crates.io | 配置管理，完全开源     |
| compass-download  | crates.io | 下载库，完全开源       |
| compass-auth      | crates.io | 认证库，开源           |
| compass-minecraft | 延迟发布  | 核心功能，稳定后开源   |
| compass-launcher  | 不发布    | 应用不发布到 crates.io |

### 版本管理

```toml
# 内部开发阶段
compass-core = { path = "../compass-core" }

# 发布后
compass-core = "0.1"

# 开发时覆盖
[patch.crates-io]
compass-core = { path = "../compass-core" }
```

## 开发工作流

### 添加新包

```bash
# 1. 创建包目录
cargo new --lib packages/compass-new-module

# 2. 添加到 Workspace
# 编辑根 Cargo.toml，添加 "packages/compass-new-module" 到 members

# 3. 配置包
# 编辑 packages/compass-new-module/Cargo.toml
# 添加 workspace = true 和依赖

# 4. 在其他包中使用
# compass-new-module = { workspace = true }
```

### 本地调试

```bash
# 运行特定包的测试
cargo test -p compass-download

# 检查特定包
cargo check -p compass-minecraft

# 构建整个 Workspace
cargo build --workspace
```

## 最佳实践

### 包设计原则

1. **单一职责**：每个包只负责一个领域
2. **最小依赖**：减少外部依赖，优先使用标准库
3. **向后兼容**：公共 API 变更遵循 SemVer
4. **文档优先**：公共 API 必须有文档和示例

### 依赖管理

1. **Workspace 统一版本**：公共依赖在 Workspace 定义
2. **特性标志**：使用 features 控制可选功能
3. **避免循环依赖**：包之间不能循环依赖

### 代码复用

1. **优先使用 compass-core**：通用工具放在 core
2. **不要重复实现**：已有功能直接依赖对应包
3. **保持接口稳定**：公共 API 变更需要谨慎
