# Compass Launcher 开发计划

## 开发阶段概览

```
Phase 1: MVP 核心功能 (v0.1.0)
├── 项目初始化
├── 基础架构搭建
├── 正版登录
├── 离线模式
├── 版本管理
├── Mod 加载器支持
└── Java 管理

Phase 2: 功能扩展 (v0.2.0)
├── 整合包支持
├── 皮肤管理
├── 联机功能
├── 日志系统
└── 服务器列表

Phase 3: 高级功能 (v0.3.0)
├── 资源集中存储 (pnpm式)
├── 性能监控
├── 云同步
└── 自动更新

Phase 4: 稳定发布 (v1.0.0)
├── Bug 修复
├── 性能优化
├── 文档完善
└── 正式发布
```

## 风险和对策

| 风险                   | 影响 | 对策                       |
| ---------------------- | ---- | -------------------------- |
| Microsoft OAuth 变更   | 高   | 关注官方文档，预留适配时间 |
| Minecraft 版本格式变更 | 中   | 抽象版本解析层，便于适配   |
| Tauri 限制             | 中   | 提前验证技术可行性         |
| 命名管道通信稳定性     | 中   | 充分测试，设计重连机制     |
| .NET Core 服务生命周期 | 中   | 设计服务自启动/守护机制    |
| 下载源不稳定           | 中   | 实现镜像源切换             |
| 开发进度延迟           | 中   | MVP 优先，功能可裁剪       |
