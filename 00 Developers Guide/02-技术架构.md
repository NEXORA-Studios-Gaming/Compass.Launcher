## 离线模式 UUID 生成规范

离线模式（离线账号）的 UUID 需要根据用户名生成，遵循以下规则：

### 算法

```rust
use uuid::Uuid;

/// 生成离线模式 UUID
/// 算法：UUID("OfflinePlayer:" + username 的 MD5 哈希)
pub fn generate_offline_uuid(username: &str) -> Uuid {
    let input = format!("OfflinePlayer:{}", username);
    let hash = md5::compute(input.as_bytes());
    
    // 设置 UUID 版本为 3（MD5 哈希）
    let mut bytes = hash.0;
    bytes[6] = (bytes[6] & 0x0F) | 0x30; // 版本 3
    bytes[8] = (bytes[8] & 0x3F) | 0x80; // 变体 10
    
    Uuid::from_bytes(bytes)
}

#[cfg(test)]
mod tests {
    use super::*;
    
    #[test]
    fn test_offline_uuid() {
        // 测试用例：用户名 "Notch"
        let uuid = generate_offline_uuid("Notch");
        assert_eq!(
            uuid.to_string(),
            "069a79f4-44e9-4726-a5be-fca90e38aaf5"
        );
    }
}
```

### 注意事项

1. **大小写敏感**: 用户名区分大小写，"Player" 和 "player" 会生成不同的 UUID
2. **不可更改**: 离线账号一旦创建，用户名不可更改（否则 UUID 会变，导致存档丢失）
3. **与正版隔离**: 离线 UUID 与正版 UUID 不冲突，即使用户名相同

## 安全考虑

1. **Token 存储**
    - 使用系统密钥链存储敏感信息
    - 不将 Token 明文保存在配置文件

2. **文件校验**
    - 所有下载文件进行 SHA1 校验
    - 防止中间人攻击

3. **进程隔离**
    - 游戏进程以子进程运行
    - 限制游戏对启动器的影响

4. **代码签名**
    - 发布版本进行代码签名
    - 避免杀毒软件误报

```rust
pub struct CrashAnalyzer;

impl CrashAnalyzer {
    /// 分析崩溃日志
    pub fn analyze(log: &str) -> CrashReport {
        let mut report = CrashReport::new();

        // 检测常见崩溃类型
        if log.contains("OutOfMemoryError") {
            report.cause = CrashCause::OutOfMemory;
            report.suggestion = "建议增加分配内存或关闭其他程序".to_string();
        } else if log.contains("GLFW error") {

            report.cause = CrashCause::ModIncompatibility;
            report.suggestion = "检查 Mod 版本兼容性".to_string();
        }

        report
    }
```

## 多开支持

### 实现方案

```rust
pub struct ProcessManager {
    running_instances: HashMap<String, Child>,
}

impl ProcessManager {
    /// 启动新实例
    pub async fn launch(&mut self, instance: &Instance) -> Result<()> {
        // 检查是否已运行
        if self.running_instances.contains_key(&instance.id) {
            return Err(Error::AlreadyRunning);
        }

        let child = launch_game(instance).await?;
        self.running_instances.insert(instance.id.clone(), child);

        // 监听进程退出
        self.watch_process(instance.id.clone());

        Ok(())
    }

    /// 获取运行中的实例
    pub fn get_running(&self) -> Vec<&String>;

    /// 强制停止实例
    pub async fn kill(&mut self, instance_id: &str) -> Result<()>;
}
```

```rust
use clap::Parser;

#[derive(Parser)]

struct Cli {
    #[command(subcommand)]
    command: Commands,
}

#[derive(Subcommand)]
enum Commands {
    Launch { instance_id: String },
    List,
    Install { version: String },
}

pub async fn run_cli(cli: Cli) -> Result<()> {
    match cli.command {
        Commands::Launch { instance_id } => {
            launch_instance(&instance_id).await
        }
        Commands::List => {
            list_instances().await
        }
        Commands::Install { version } => {

        }
    }
}
```

```rust
pub enum LaunchMode {
    Normal,
    Debug,
}

pub struct LaunchWindow {
    mode: LaunchMode,
    log_buffer: Vec<String>,
}

impl LaunchWindow {
    pub fn show_progress(&mut self, stage: &str, progress: f32);
    pub fn append_log(&mut self, line: &str);
    pub fn close_on_complete(&self) -> bool {
        matches!(self.mode, LaunchMode::Normal)
    }
}
```
