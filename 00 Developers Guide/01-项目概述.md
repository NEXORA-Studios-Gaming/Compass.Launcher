# Compass Launcher 项目概述

## 项目简介

**Compass Launcher** 是一款现代化的 Minecraft 启动器，采用 Tauri (Rust + Web) 技术栈构建，支持跨平台运行。

### 核心理念

- **MVP 优先**：先实现核心启动功能，快速发布可用版本
- **游戏风格 UI**：Minecraft 主题风格设计，融入像素元素
- **资源优化**：采用类似 pnpm 的资源集中存储机制，节省磁盘空间

---

## 技术栈

| 层级      | 技术                      | 说明                             |
| --------- | ------------------------- | -------------------------------- |
| 后端/原生 | Tauri (Rust)              | 跨平台桌面应用框架，提供原生能力 |
| 前端框架  | React 18 + TypeScript     | 成熟的前端技术栈                 |
| UI 组件   | shadcn/ui                 | 基于 Radix UI 的高质量组件库     |
| 样式      | TailwindCSS 4             | 实用优先的 CSS 框架              |
| 构建工具  | Vite                      | 快速的开发构建工具               |

## 核心功能规划

### 第一阶段 (MVP)

1. **正版登录** - Microsoft 账号登录（内置浏览器 OAuth）
2. **离线模式** - 支持离线游戏

> **注意**: Mojang 账号系统已于 2023 年 3 月完全迁移至 Microsoft 账号，不再支持独立的 Mojang 认证
3. **多版本管理** - 安装、切换不同 Minecraft 版本
4. **Mod 加载器** - Forge、Fabric、Quilt 支持
5. **Java 管理** - 自动检测系统 Java + 内置下载
6. **多开支持** - 可同时运行多个游戏实例
7. **崩溃分析** - 自动分析崩溃原因并提供解决方案

### 第二阶段

1. **整合包支持** - CurseForge、Modrinth 整合包安装（内置浏览器一键安装）
2. **皮肤管理** - 本地皮肤、正版皮肤、第三方皮肤站
3. **联机功能** - 局域网、第三方联机服务、服务器列表
4. **日志系统** - 游戏日志查看、一键导出
5. **Mod 生态** - 完整的 Mod 浏览、下载、管理功能
6. **实例导入导出** - 支持 HMCL/PCL 格式、分享码

### 第三阶段

1. **资源集中存储** - pnpm 式 libraries/assets 单份存储
2. **性能监控** - 实时游戏性能监控
3. **云同步** - 配置云端同步（存档不同步）
4. **自动更新** - 可配置的更新机制
5. **命令行支持** - 快速启动指定实例

### 实验性功能 (AI) - Post-v1.0

> **注意**: AI 功能为远期规划，v1.0 版本不包含以下功能

1. **AI 智能助手** - 悬浮球聊天界面，命令触发
2. **崩溃分析专家** - 自动分析崩溃日志，定位问题 Mod
3. **配置优化师** - 根据硬件推荐最佳 JVM 参数和游戏设置
4. **游戏向导** - 回答游戏玩法、合成配方等问题
5. **多模型支持** - 本地模型 + 云端 API，用户自选

详见 [05-AI功能设计.md](./05-AI功能设计.md)

## 游戏实例管理

### 目录结构

```
.minecraft/
├── libraries/              # 共享库文件
├── assets/                 # 共享资源文件
├── versions/               # 版本隔离目录
│   ├── 1.20.1/
│   ├── 1.20.1-forge/
│   └── fabric-1.20.1/
├── instances/              # 实例配置
│   ├── 生存存档/
│   ├── 创造建筑/
│   └── 整合包-RLCraft/
└── launcher-config.json    # 启动器配置
```

### 实例隔离策略

- 每个实例拥有独立的 `versions/<version>/` 目录
- `libraries` 和 `assets` 在 `.minecraft` 级别共享
- 存档、配置、Mod 按实例隔离

---

## 资源集中存储 (pnpm式)

### 设计目标

- 多个实例共享相同的 libraries 和 assets
- 通过硬链接/符号链接机制实现
- 显著减少磁盘空间占用

### 实现思路

```
.minecraft/
├── .store/                 # 集中存储库
│   ├── libraries/
│   │   └── <hash>/         # 按内容哈希存储
│   └── assets/
│       └── <hash>/
├── versions/
│   └── 1.20.1/
│       └── libraries/ -> ../../.store/libraries/<hash>/  # 链接
```

## 更新机制

### 用户可配置选项

1. **仅手动检查** - 完全由用户控制
2. **自动检查** - 启动时检查新版本并提示
3. **静默下载** - 后台下载更新，完成后提示安装

### 版本更新提醒

- 检测 Minecraft 新版本发布
- 可配置是否自动检查
- 显示更新日志

## 数据存储

### 存储位置

| 数据类型 | 存储位置 |
|----------|----------|
| **启动器配置** | 应用数据目录 (`%APPDATA%/CompassLauncher`) |
| **账户信息** | 系统密钥链 |
| **实例配置** | 游戏目录 (`.minecraft/instances/`) |
| **缓存数据** | 应用数据目录 |

### 特性

- 游戏目录可自定义配置
- 敏感信息使用系统密钥链存储
- 支持多设备配置迁移
