# Compass Launcher AI 功能设计

> **⚠️ 远期目标 (Post-v1.0)**
> 
> 本文档描述的 AI 功能为**远期规划目标**，不在 MVP (v0.1.0) 或 v1.0 版本中实现。
> 
> **原因**:
> - AI 功能需要大量训练数据和模型调优
> - 崩溃分析、配置优化等功能需要长期迭代验证
> - 核心启动器功能（启动游戏、版本管理）优先级更高
> 
> **建议**: 先专注于核心启动器功能，待 v1.0 稳定后再考虑集成 AI 功能。

## 概述

Compass Launcher 计划集成 AI 助手功能，为 Minecraft 玩家提供智能化的游戏辅助服务。AI 助手以**实验性功能**形式提供，用户可自主选择是否启用。

## 核心理念

- **专业助手**：严谨、专业的技术助手风格
- **用户控制**：玩家完全掌控 AI 访问的数据范围
- **隐私优先**：本地处理优先，云端通信加密且匿名
- **灵活配置**：支持多种 AI 模型和接入方式

---

## AI 助手角色定位

### 主要功能

| 角色             | 功能描述                                     |
| ---------------- | -------------------------------------------- |
| **崩溃分析专家** | 深度分析崩溃日志，识别崩溃类型，定位问题 Mod |
| **配置优化师**   | 根据硬件配置推荐最佳 JVM 参数和游戏设置      |
| **游戏向导**     | 回答游戏玩法、合成配方、机制问题             |

### 交互方式

1. **悬浮球/快捷入口**
    - 主界面右下角悬浮 AI 助手图标
    - 点击展开聊天窗口
    - 支持拖拽调整位置

2. **命令触发**
    - `/ai 分析崩溃` - 分析最近崩溃日志
    - `/ai 优化配置` - 获取配置优化建议
    - `/ai 推荐 Mod` - 根据喜好推荐 Mod
    - `/ai 如何制作铁镐` - 游戏问题解答

3. **主动推送**
    - 游戏崩溃后自动分析并弹出建议
    - 定期推送配置优化建议（可选）

## AI 模型配置

### 支持的模式

| 模式         | 说明                               | 适用场景           |
| ------------ | ---------------------------------- | ------------------ |
| **本地模型** | 运行在本地的开源模型               | 隐私敏感、离线使用 |
| **云端 API** | 调用第三方 API                     | 高性能需求         |
| **混合模式** | 本地处理简单任务，复杂任务调用云端 | 平衡性能与隐私     |

### 用户配置选项

```typescript
interface AiConfig {
    // 是否启用 AI 功能
    enabled: boolean;

    // 模型类型: 'local' | 'cloud' | 'hybrid'
    mode: "local" | "cloud" | "hybrid";

    // 本地模型配置
    localModel?: {
        model: "llama3" | "qwen2.5" | "custom";
        path: string;
        maxTokens: number;
    };

    // 云端 API 配置
    cloudApi?: {
        provider: "openai" | "anthropic" | "gemini" | "custom";
        apiKey: string;
        model: string;
        baseUrl?: string;
    };

    // 功能开关
    features: {
        crashAnalysis: boolean;
        configOptimization: boolean;
        gameGuide: boolean;
        proactiveSuggestions: boolean;
    };

    // 隐私设置
    privacy: {
        shareGameData: boolean;
        shareCrashLogs: boolean;
        shareSystemSpecs: boolean;
        anonymizeData: boolean;
    };

    // 语言设置

```

## 功能详细设计

### 1. 崩溃分析专家

#### 功能描述

自动分析 Minecraft 崩溃日志，识别崩溃原因，定位问题 Mod，提供解决方案。

#### 工作流程

```
游戏崩溃
    │
    ▼
┌─────────────────┐
│ 1. 捕获崩溃日志  │
│   - latest.log  │
│   - crash-report│
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 2. AI 分析      │
│   - 识别异常类型 │
│   - 定位错误位置 │
│   - 分析 Mod 冲突│
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 3. 生成报告     │
│   - 崩溃原因    │
│   - 涉及 Mod    │
│   - 修复建议    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 4. 推送建议     │
│   - 弹窗通知    │
│   - 一键修复    │
└─────────────────┘
```

#### 分析维度

- **内存溢出**：建议增加分配内存
- **Mod 冲突**：识别冲突的 Mod 组合
- **版本不兼容**：Mod 与游戏版本不匹配
- **驱动问题**：显卡驱动相关错误
- **Java 问题**：Java 版本或参数问题

#### 输出示例

```json
{

    "analysis": "检测到 Sodium 和 OptiFine 同时安装导致冲突",

    "suggestions": [
        {
            "action": "remove",
            "target": "optifine_HD_U_I5",
            "reason": "Sodium 和 OptiFine 功能重复且不兼容"
        },
        {
            "action": "alternative",
            "target": "iris-mc1.20.1-1.6.0",
            "reason": "Iris 与 Sodium 兼容，提供光影支持"
        }
    ],
    "auto_fixable": true
}
```

### 2. 配置优化师

#### 功能描述

根据用户硬件配置和游戏习惯，智能推荐最佳的 JVM 参数和游戏设置。

#### 收集的数据

```rust
pub struct SystemSpecs {
    // CPU
    pub cpu_cores: usize,
    pub cpu_threads: usize,
    pub cpu_model: String,

    // 内存
    pub total_memory: u64,      // MB
    pub available_memory: u64,  // MB

    // 显卡
    pub gpu_model: String,
    pub gpu_vram: u64,          // MB

    // 存储
    pub disk_type: DiskType,    // SSD / HDD
    pub disk_free: u64,         // GB

    // 系统
    pub os: String,
    pub java_version: String,
}

pub struct GameProfile {
    // 游戏习惯
    pub avg_session_time: u32,  // 分钟
    pub preferred_mod_count: u32,
    pub shader_usage: bool,
    pub server_play_ratio: f32, // 0-1
}
```

#### 优化建议

| 配置项   | 低配置 | 中配置 | 高配置 |
| -------- | ------ | ------ | ------ |
| 分配内存 | 2-4GB  | 4-6GB  | 8GB+   |
| 视距     | 8-10   | 12-16  | 20-32  |
| 粒子效果 | 最少   | 适度   | 全部   |
| 光影     | 关闭   | 轻量   | 重度   |
| JVM GC   | G1GC   | ZGC    | ZGC    |

## 隐私与安全

### 数据收集策略

| 数据类型     | 收集方式       | 用途            |
| ------------ | -------------- | --------------- |
| **崩溃日志** | 用户授权后上传 | AI 分析崩溃原因 |
| **系统配置** | 本地读取       | 优化建议        |
| **游戏设置** | 本地读取       | 个性化建议      |
| **Mod 列表** | 本地读取       | 冲突检测、推荐  |

### 隐私保护措施

1. **本地优先**
    - 简单查询优先使用本地知识库
    - 本地模型处理敏感数据
    - 云端仅处理复杂分析任务

2. **数据匿名化**
    - 上传前去除用户名、路径等个人信息
    - 使用哈希值代替敏感标识
    - 不收集游戏存档内容

3. **透明政策**
    - 明确告知用户哪些数据会被发送
    - 提供详细的数据使用说明
    - 用户可随时查看已分享的数据

4. **端到端加密**
    - 与云端通信使用 HTTPS
    - API Key 本地加密存储
    - 支持代理服务器

### 用户控制

```typescript
interface PrivacySettings {
    // 完全禁用 AI
    disableAi: boolean;

    // 功能级控制
    allowCrashAnalysis: boolean;
    allowConfigOptimization: boolean;

    // 数据级控制

    shareModList: boolean;
    shareCrashLogs: boolean;

    // 处理方式

    anonymizeBeforeSend: boolean;
}
```
