# Compass Launcher 代码架构设计

## 架构概述

Compass Launcher 采用**微内核架构**（Microkernel Architecture），核心系统提供基础服务，功能通过插件/模块方式扩展。这种架构保证了系统的可扩展性和可维护性。

## 架构原则

1. **单一职责**：每个模块只负责一个功能领域
2. **依赖倒置**：高层模块不依赖低层模块，都依赖抽象
3. **事件驱动**：模块间通过事件松耦合通信
4. **错误隔离**：错误不影响整个系统稳定性

## 微内核架构详解

### 核心（Kernel）

核心提供最小化的基础服务，所有其他功能都构建在核心之上。

```rust
// core/kernel.rs
pub struct Kernel {
    config: Arc<ConfigManager>,
    event_bus: Arc<EventBus>,
    plugin_manager: Arc<PluginManager>,
    logger: Arc<Logger>,
    error_handler: Arc<ErrorHandler>,
}

impl Kernel {
    pub async fn new() -> Result<Self> {
        // 初始化核心服务
        let config = Arc::new(ConfigManager::new().await?);
        let event_bus = Arc::new(EventBus::new());
        let logger = Arc::new(Logger::new(config.clone()).await?);
        let error_handler = Arc::new(ErrorHandler::new(logger.clone()));
        let plugin_manager = Arc::new(PluginManager::new(event_bus.clone()));

        Ok(Self {
            config,
            event_bus,
            plugin_manager,
            logger,
            error_handler,
        })
    }

    /// 启动核心
    pub async fn start(&self) -> Result<()> {
        self.logger.info("Kernel starting...");
        self.event_bus.start().await?;
        self.plugin_manager.load_plugins().await?;
        Ok(())
    }

    /// 获取服务
    pub fn get_service<T: Service>(&self) -> Option<Arc<T>>;
}
```

## 事件驱动架构

### 事件总线

```rust
// core/event_bus.rs
pub struct EventBus {
    subscribers: RwLock<HashMap<EventType, Vec<Box<dyn EventHandler>>>>,
    sender: mpsc::Sender<Event>,
    receiver: Mutex<mpsc::Receiver<Event>>,
}

#[derive(Clone, Debug)]
pub enum Event {
    // 游戏事件
    GameLaunching { instance_id: String },
    GameStarted { instance_id: String, pid: u32 },
    GameStopped { instance_id: String, exit_code: i32 },
    GameCrashed { instance_id: String, log_path: PathBuf },

    // 下载事件
    DownloadStarted { id: String, url: String, total: u64 },
    DownloadProgress { id: String, downloaded: u64, speed: u64 },
    DownloadCompleted { id: String },
    DownloadFailed { id: String, error: String },

    // 配置事件
    ConfigChanged { key: String, old_value: Value, new_value: Value },

    // 账户事件
    AccountAdded { account_id: String },
    AccountRemoved { account_id: String },
    AccountSwitched { account_id: String },

    // AI 事件
    AiSuggestion { suggestion_type: String, content: String },
}

#[async_trait]
pub trait EventHandler: Send + Sync {
    async fn handle(&self, event: &Event);
    fn event_types(&self) -> Vec<EventType>;
}

impl EventBus {
    /// 发布事件
    pub async fn publish(&self, event: Event) {
        let _ = self.sender.send(event).await;
    }

    /// 订阅事件
    pub async fn subscribe(&self, handler: Box<dyn EventHandler>) {
        let mut subscribers = self.subscribers.write().await;
        for event_type in handler.event_types() {
            subscribers.entry(event_type)
                .or_insert_with(Vec::new)
                .push(handler.clone_box());
        }
    }

    /// 事件分发循环
    async fn dispatch_loop(&self) {
        while let Ok(event) = self.receiver.lock().await.recv().await {
            let subscribers = self.subscribers.read().await;
            if let Some(handlers) = subscribers.get(&event.event_type()) {
                for handler in handlers {
                    let event = event.clone();
                    tokio::spawn(async move {
                        handler.handle(&event).await;
                    });
                }
            }
        }
    }
}
```

```rust
// core/error_handler.rs
pub struct ErrorHandler {
    logger: Arc<Logger>,
    reporter: Arc<dyn ErrorReporter>,
    recovery_strategies: Vec<Box<dyn RecoveryStrategy>>,
}

impl ErrorHandler {
    /// 处理错误
    pub async fn handle(&self, error: LauncherError, context: ErrorContext) -> ErrorAction {
        // 记录错误
        self.logger.error(&format!("Error: {}, Context: {:?}", error, context));

        // 尝试恢复
        for strategy in &self.recovery_strategies {
            if strategy.can_recover(&error) {
                match strategy.recover(&error).await {
                    Ok(()) => return ErrorAction::Recovered,
                    Err(e) => {
                        self.logger.warn(&format!("Recovery failed: {}", e));
                    }
                }
            }
        }

        // 报告错误
        if self.should_report(&error) {
            self.reporter.report(&error, &context).await;
        }

        // 通知用户
        ErrorAction::NotifyUser(error.to_string())
    }

    /// 添加恢复策略
    pub fn add_recovery_strategy(&mut self, strategy: Box<dyn RecoveryStrategy>) {
        self.recovery_strategies.push(strategy);
    }
}

/// 恢复策略
#[async_trait]
pub trait RecoveryStrategy: Send + Sync {
    fn can_recover(&self, error: &LauncherError) -> bool;
    async fn recover(&self, error: &LauncherError) -> Result<()>;
}

/// 下载重试策略
pub struct DownloadRetryStrategy {
    max_retries: u32,
    delay: Duration,
}

#[async_trait]
impl RecoveryStrategy for DownloadRetryStrategy {
    fn can_recover(&self, error: &LauncherError) -> bool {
        matches!(error, LauncherError::Network(_))
    }

    async fn recover(&self, error: &LauncherError) -> Result<()> {
        // 实现重试逻辑
        Ok(())
    }
}
```

### 结构化日志

```rust
// core/logger.rs
use tracing::{info, warn, error, debug, span, Level};
use tracing_subscriber::{layer::SubscriberExt, util::SubscriberInitExt};

pub struct Logger {
    config: Arc<ConfigManager>,
}

impl Logger {
    pub async fn new(config: Arc<ConfigManager>) -> Result<Self> {
        // 初始化日志订阅器
        let file_appender = tracing_appender::rolling::daily(
            config.log_dir(),
            "compass-launcher.log"
        );

        let (non_blocking, _guard) = tracing_appender::non_blocking(file_appender);

        tracing_subscriber::registry()
            .with(
                tracing_subscriber::EnvFilter::try_from_default_env()
                    .unwrap_or_else(|_| "info".into())
            )
            .with(
                tracing_subscriber::fmt::layer()
                    .json()
                    .with_writer(non_blocking)
            )
            .with(
                tracing_subscriber::fmt::layer()
                    .with_writer(std::io::stdout)
            )
            .init();

        Ok(Self { config })
    }

    /// 创建带上下文的 span
    pub fn create_span(&self, operation: &str, params: HashMap<String, Value>) -> tracing::Span {
        let span = span!(Level::INFO, "operation", %operation);
        for (key, value) in params {
            span.record(&key, &value.to_string());
        }
        span
    }
}

/// 日志宏
#[macro_export]
macro_rules! log_operation {
    ($logger:expr, $operation:expr, $params:expr, $block:block) => {
        {
            let span = $logger.create_span($operation, $params);
            let _enter = span.enter();

            tracing::info!("Operation started: {}", $operation);

            let result = async { $block }.await;

            match &result {
                Ok(_) => tracing::info!("Operation completed: {}", $operation),
                Err(e) => tracing::error!("Operation failed: {}, error: {}", $operation, e),
            }

            result
        }
    };
}
```

### 配置分层

```rust
// core/config.rs
pub struct ConfigManager {
    /// 静态配置（编译时）
    static_config: StaticConfig,

    /// 文件配置（持久化）
    file_config: RwLock<FileConfig>,

    /// 环境变量配置
    env_config: EnvConfig,

    /// 运行时配置（动态）
    runtime_config: RwLock<HashMap<String, Value>>,

    /// 配置变更监听器
    listeners: RwLock<Vec<Box<dyn ConfigListener>>>,
}

impl ConfigManager {
    /// 获取配置值（按优先级）
    pub async fn get(&self, key: &str) -> Option<Value> {
        // 1. 运行时配置（最高优先级）
        if let Some(value) = self.runtime_config.read().await.get(key) {
            return Some(value.clone());
        }

        // 2. 环境变量
        if let Some(value) = self.env_config.get(key) {
            return Some(value);
        }

        // 3. 文件配置
        if let Some(value) = self.file_config.read().await.get(key) {
            return Some(value.clone());
        }

        // 4. 静态配置
        self.static_config.get(key)
    }

    /// 设置运行时配置
    pub async fn set(&self, key: &str, value: Value) -> Result<()> {
        let old_value = self.runtime_config.read().await.get(key).cloned();

        self.runtime_config.write().await.insert(key.to_string(), value.clone());

        // 通知监听器
        self.notify_listeners(ConfigChangeEvent {
            key: key.to_string(),
            old_value,
            new_value: value,
        }).await;

        Ok(())
    }

    /// 持久化配置
    pub async fn persist(&self) -> Result<()> {
        let config = self.file_config.read().await;
        let content = serde_json::to_string_pretty(&*config)?;
        fs::write(self.config_path(), content).await?;
        Ok(())
    }

    /// 热重载配置
    pub async fn reload(&self) -> Result<()> {
        let content = fs::read_to_string(self.config_path()).await?;
        let config: FileConfig = serde_json::from_str(&content)?;
        *self.file_config.write().await = config;
        Ok(())
    }
}
```

### 使用依赖注入容器

```rust
// core/di.rs
use std::any::{Any, TypeId};
use std::collections::HashMap;
use std::sync::Arc;

pub struct Container {
    services: HashMap<TypeId, Arc<dyn Any + Send + Sync>>,
    factories: HashMap<TypeId, Box<dyn Fn(&Container) -> Arc<dyn Any + Send + Sync>>>,
}

impl Container {
    pub fn new() -> Self {
        Self {
            services: HashMap::new(),
            factories: HashMap::new(),
        }
    }

    /// 注册单例服务
    pub fn register_singleton<T: Send + Sync + 'static>(&mut self, instance: Arc<T>) {
        self.services.insert(TypeId::of::<T>(), instance);
    }

    /// 注册工厂
    pub fn register_factory<T: Send + Sync + 'static>(
        &mut self,
        factory: Box<dyn Fn(&Container) -> Arc<T>>,
    ) {
        self.factories.insert(TypeId::of::<T>(), Box::new(move |c| {
            factory(c) as Arc<dyn Any + Send + Sync>
        }));
    }

    /// 获取服务
    pub fn resolve<T: Send + Sync + 'static>(&self) -> Option<Arc<T>> {
        // 先查找已实例化的服务
        if let Some(service) = self.services.get(&TypeId::of::<T>()) {
            return service.clone().downcast::<T>().ok();
        }

        // 使用工厂创建
        if let Some(factory) = self.factories.get(&TypeId::of::<T>()) {
            let instance = factory(self);
            return instance.downcast::<T>().ok();
        }

        None
    }
}

/// 模块 trait
pub trait Module {
    fn configure(&self, container: &mut Container);
}

/// 注册所有模块
pub fn configure_services(container: &mut Container) {
    // 核心服务
    container.register_singleton::<Arc<ConfigManager>>(
        Arc::new(ConfigManager::new())
    );

    container.register_singleton::<Arc<EventBus>>(
        Arc::new(EventBus::new())
    );

    // 功能模块
    MinecraftModule.configure(container);
    AuthModule.configure(container);
    AiModule.configure(container);
}
```

## 缓存策略

### 多级缓存

```rust
// core/cache.rs
pub struct CacheManager {
    /// L1 缓存 - 内存
    memory: Arc<RwLock<LruCache<String, CachedValue>>>,

    /// L2 缓存 - 磁盘
    disk: Arc<DiskCache>,

    /// 缓存统计
    stats: Arc<RwLock<CacheStats>>,
}

pub struct CachedValue {
    data: Vec<u8>,
    etag: Option<String>,
    expires_at: DateTime<Utc>,
    access_count: AtomicU32,
}

impl CacheManager {
    /// 获取缓存
    pub async fn get(&self, key: &str) -> Option<Vec<u8>> {
        // 1. 尝试内存缓存
        if let Some(value) = self.memory.read().await.get(key) {
            if value.expires_at > Utc::now() {
                value.access_count.fetch_add(1, Ordering::Relaxed);
                return Some(value.data.clone());
            }
        }

        // 2. 尝试磁盘缓存
        if let Some(value) = self.disk.get(key).await {
            // 回填内存缓存
            self.memory.write().await.put(key.to_string(), CachedValue {
                data: value.clone(),
                etag: None,
                expires_at: Utc::now() + Duration::hours(1),
                access_count: AtomicU32::new(1),
            });
            return Some(value);
        }

        None
    }

    /// 智能清理
    pub async fn gc(&self) {
        let mut stats = self.stats.write().await;

        // 根据访问频率和大小决定清理策略
        if stats.memory_usage > MAX_MEMORY_CACHE {
            // 清理最少访问的条目
            self.memory.write().await.prune_by_access_count(0.2);
        }

        if stats.disk_usage > MAX_DISK_CACHE {
            // 清理过期条目
            self.disk.clean_expired().await;
        }
    }
}
```

```rust
    client: reqwest::Client,
    request_queue: Arc<RequestQueue>,
    retry_policy: RetryPolicy,
    interceptors: Vec<Box<dyn RequestInterceptor>>,
}

pub struct RequestQueue {
    semaphore: Arc<Semaphore>,
    pending: Arc<RwLock<Vec<QueuedRequest>>>,
}

impl NetworkManager {
    /// 发送请求（带队列和重试）
    pub async fn request(&self, req: Request) -> Result<Response> {
        // 1. 应用拦截器
        let req = self.apply_interceptors(req).await?;

        // 2. 获取队列许可
        let _permit = self.request_queue.semaphore.acquire().await?;

        // 3. 执行请求（带重试）
        let mut last_error = None;
        for attempt in 0..self.retry_policy.max_retries {
            match self.execute(&req).await {
                Ok(resp) => return Ok(resp),
                Err(e) if self.retry_policy.should_retry(&e) => {
                    last_error = Some(e);
                    tokio::time::sleep(self.retry_policy.delay(attempt)).await;
                }
                Err(e) => return Err(e),
            }
        }

        Err(last_error.unwrap())
    }

    /// 断点续传下载
    pub async fn download_with_resume(
        &self,
        url: &str,
        path: &Path,
    ) -> Result<()> {
        let temp_path = path.with_extension("tmp");

        // 获取已下载大小
        let start = if temp_path.exists() {
            fs::metadata(&temp_path).await?.len()
        } else {
            0
        };

        // 发送 Range 请求
        let resp = self.client
            .get(url)
            .header("Range", format!("bytes={}-", start))
            .send()
            .await?;

        // 追加写入
        let mut file = fs::OpenOptions::new()
            .create(true)
            .append(true)
            .open(&temp_path)
            .await?;

        let mut stream = resp.bytes_stream();
        while let Some(chunk) = stream.next().await {
            file.write_all(&chunk?).await?;
        }

        // 重命名为最终文件
        fs::rename(&temp_path, path).await?;

        Ok(())
    }
}
```

### 路径规范

```rust
// core/path.rs
use std::path::{Path, PathBuf};

pub struct PathManager;

impl PathManager {
    /// 获取游戏目录（跨平台）
    pub fn game_dir() -> PathBuf {
        #[cfg(target_os = "windows")]
        {
            dirs::data_dir()
                .expect("Failed to get data dir")
                .join(".minecraft")
        }
        
        #[cfg(target_os = "macos")]
        {
            dirs::home_dir()
                .expect("Failed to get home dir")
                .join("Library/Application Support/minecraft")
        }
        
        #[cfg(target_os = "linux")]
        {
            dirs::home_dir()
                .expect("Failed to get home dir")
                .join(".minecraft")
        }
    }
    
    /// 获取启动器配置目录
    pub fn launcher_dir() -> PathBuf {
        dirs::config_dir()
            .expect("Failed to get config dir")
            .join("CompassLauncher")
    }
    
    /// 规范化路径（处理分隔符、相对路径等）
    pub fn normalize(path: &str) -> PathBuf {
        let path = PathBuf::from(path);
        
        // 展开 ~ 为用户主目录
        let path = if path.starts_with("~") {
            dirs::home_dir()
                .map(|home| home.join(path.strip_prefix("~").unwrap_or(&path)))
                .unwrap_or(path)
        } else {
            path
        };
        
        // 转换为绝对路径
        std::fs::canonicalize(&path).unwrap_or(path)
    }
    
    /// 验证路径安全性（防止路径遍历攻击）
    pub fn is_safe_path(path: &Path, base: &Path) -> bool {
        // 解析为绝对路径
        let absolute = if path.is_absolute() {
            path.to_path_buf()
        } else {
            base.join(path)
        };
        
        // 检查是否在 base 目录下
        let canonical_base = std::fs::canonicalize(base).ok()?;
        let canonical_path = std::fs::canonicalize(&absolute).ok()?;
        
        canonical_path.starts_with(&canonical_base)
    }
}
```

### 路径分隔符处理

| 平台 | 分隔符 | 示例 |
|------|--------|------|
| Windows | `\` 或 `/` | `C:\Users\name\.minecraft` |
| macOS | `/` | `/Users/name/Library/Application Support/minecraft` |
| Linux | `/` | `/home/name/.minecraft` |

### 注意事项

1. **始终使用 PathBuf**: 不要手动拼接路径字符串
2. **使用 Path 的 join 方法**: `path.join("subdir")` 会自动处理分隔符
3. **避免硬编码路径**: 使用 `dirs` crate 获取系统目录
4. **验证用户输入路径**: 防止路径遍历攻击

```rust
    /// 错误，需要处理

    /// 致命错误，无法继续
    Fatal,

            LauncherError::FileOperation { .. } => ErrorSeverity::Error,
            LauncherError::Network { .. } => ErrorSeverity::Warning,
            LauncherError::Download { .. } => ErrorSeverity::Warning,
            LauncherError::Checksum { .. } => ErrorSeverity::Error,
            LauncherError::Auth(_) => ErrorSeverity::Error,
            LauncherError::Launch(_) => ErrorSeverity::Fatal,
            LauncherError::Config(_) => ErrorSeverity::Warning,
        }
    }
    
    /// 是否可重试
    pub fn is_retryable(&self) -> bool {
        matches!(self, 
            LauncherError::Network { .. } | 
            LauncherError::Download { .. }
        )
    }
```

### 常见错误场景处理

```rust
// 下载失败处理
pub async fn download_with_retry(
    url: &str,
    path: &Path,
    max_retries: u32,
) -> Result<(), LauncherError> {
    for attempt in 0..max_retries {
        match download(url, path).await {
            Ok(()) => return Ok(()),
            Err(e) if e.is_retryable() && attempt < max_retries - 1 => {
                let delay = Duration::from_secs(2u64.pow(attempt));
                tracing::warn!("Download failed, retrying in {:?}: {}", delay, e);
                tokio::time::sleep(delay).await;
            }
            Err(e) => return Err(e),
        }
    }
    
    unreachable!()
}

// 文件损坏处理
pub async fn verify_or_redownload(
    path: &Path,
    url: &str,
    expected_hash: &str,
) -> Result<(), LauncherError> {
    // 检查文件是否存在
    if !path.exists() {
        return download(url, path).await;
    }
    
    // 校验文件
    match verify_file(path, expected_hash).await {
        Ok(()) => Ok(()),
        Err(LauncherError::Checksum { .. }) => {
            tracing::warn!("File checksum mismatch, redownloading: {}", path.display());
            // 删除损坏的文件
            fs::remove_file(path).await.ok();
            // 重新下载
            download(url, path).await
        }
        Err(e) => Err(e),
    }
}

// 网络超时处理
pub async fn fetch_with_timeout<T>(
    request: Request,
    timeout: Duration,
) -> Result<T, LauncherError> {
    match tokio::time::timeout(timeout, send_request(request)).await {
        Ok(Ok(response)) => Ok(response),
        Ok(Err(e)) => Err(LauncherError::Network { 
            url: request.url().to_string(), 
            source: e 
        }),
        Err(_) => Err(LauncherError::Network {
            url: request.url().to_string(),
            source: reqwest::Error::from(std::io::Error::new(
                std::io::ErrorKind::TimedOut,
                "Request timeout"
            )),
        }),
    }
}
```

```rust
// core/validation.rs
pub struct InputValidator;

impl InputValidator {
    /// 验证实例名称
    pub fn validate_instance_name(name: &str) -> Result<()> {
```
